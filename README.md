# CalcLine

CalcLine — бесплатный однострочный инженерный калькулятор для Windows 10 и новее.

Готовая программа доступна в разделе [Releases](https://github.com/Water-FAQ/CalcLine/releases). Установка не требуется: скачайте архив, распакуйте его и запустите `CalcLine.exe`.

## Возможности

- вычисление результата во время ввода;
- арифметические, процентные, тригонометрические и логарифмические операции;
- единицы измерения, проверка размерностей и автоматическая конвертация;
- история, `ans`, DEG/RAD и автодополнение;
- светлая, тёмная и системная темы.

## Системные требования

- Windows 10 или новее.
